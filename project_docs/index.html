Concurrency Engine

Pessimistic Row Locking

Bidding transactions acquire row-level PESSIMISTIC_WRITE locks in PostgreSQL, serializing millisecond bid collisions without dirty reads.

Real-Time Sync

Spring STOMP Broker

Pushes atomic bid updates to /topic/auctions/{id} and outbid notices to active participants with sub-10ms delivery.

Independent Engine

Scheduled UTC Closer

Independent background cron runs every 5 seconds, evaluating server UTC timestamps to transition auctions to awaiting seller approval or unsold.
